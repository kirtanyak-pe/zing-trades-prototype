# Zing Trades — prototype

Clickable prototype of Zing Trades: login, home, creator profile, your profile, leaderboard and profile setup.
The panel on the left switches screens, user types and states.

**Live:** https://kirtanyak-pe.github.io/zing-trades-prototype/

This repo holds only the built single-file site (`index.html`). It's published from the prototype project with
`npm run deploy`.
